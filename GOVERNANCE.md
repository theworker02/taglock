# Governance

TagLock is maintained by theworker02 as an independent open-source project.

## Decision making

Routine fixes and documentation changes are decided through normal pull-request
review. Maintainers seek technical consensus for larger changes, but the
project owner retains final responsibility for scope, security, compatibility,
release readiness, and project direction.

Decisions prioritize:

1. Correctness and user safety.
2. Low false-positive rates and explicit uncertainty.
3. Compatibility of public APIs and machine-readable formats.
4. Deterministic, maintainable implementation.
5. Performance across repository-scale analysis.

## Maintainer responsibilities

Maintainers review contributions, triage reports, coordinate security fixes,
protect release credentials, maintain CI, document compatibility decisions,
and avoid publishing work that has not passed the release checklist.

## Becoming a maintainer

Maintainer access may be offered after sustained, high-quality contributions
and demonstrated judgment in analyzer correctness, compatibility, security,
and community collaboration. Access is scoped to actual responsibility and may
be removed when inactive or when required to protect the project.

## Changes to governance

Material governance changes should be proposed publicly when security or
privacy does not require confidentiality. This document describes current
practice and does not create employment, partnership, or financial obligations.
