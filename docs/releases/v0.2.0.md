# TagLock v0.2.0 — Diagnostic Triage API

TagLock v0.2.0 adds a stable, importable triage layer for teams that consume TagLock findings outside the built-in CLI.

## Added

- New `github.com/theworker02/taglock/triage` package.
- Deterministic summaries grouped by severity, rule, category, and namespace.
- Weighted risk scores for comparing scans over time.
- Safe-fix and review-required remediation counts.
- Stable top-rule rankings with deterministic tie-breaking.
- `Summary.FailsAt` for typed CI threshold decisions.

## Compatibility

- Existing analyzer, CLI, snapshot, schema, verification, and evolution APIs are unchanged.
- The feature is additive and requires no configuration migration.
- Go 1.24 remains the minimum supported toolchain.

## Upgrade

```bash
go get github.com/theworker02/taglock@v0.2.0
```
