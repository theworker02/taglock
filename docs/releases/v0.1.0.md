# TagLock v0.1.0

TagLock's first public release brings compile-time confidence to Go struct-tag
contracts. It analyzes how serialized, validated, and persisted field surfaces
interact across an entire type instead of treating each tag as an isolated
string.

## Highlights

- Reusable `go/analysis` analyzer, standalone CLI, and custom vet-tool support.
- Normalized contracts with embedded and promoted-field resolution.
- Stable TAG rule identifiers covering syntax, fields, types, consistency,
  security, and suppression directives.
- Dedicated JSON, YAML, and XML semantics plus configurable generic namespaces.
- Safe suggested fixes with explicit safe and review-required classifications.
- Strict project configuration, file/package overrides, suppressions, and
  deterministic diagnostics.
- Text, JSON, Markdown, and SARIF reporting suitable for editors and CI.
- Durable baselines for incremental adoption in existing repositories.
- Versioned contract snapshots, evolution comparison, JSON v1-to-v2 migration
  intelligence, schema export, and generated runtime verification.
- Original TagLock logo, documentation site, community policies, and GitHub
  Pages workflow.

## Install

TagLock requires Go 1.24 or newer.

```sh
go install github.com/theworker02/taglock/cmd/taglock@v0.1.0
taglock version
taglock check ./...
```

The analyzer can also be embedded from
`github.com/theworker02/taglock/analyzer`.

## Compatibility notes

- JSON v2 runtime differential tests require a Go toolchain with
  `GOEXPERIMENT=jsonv2`; TagLock's static migration model remains available
  without it.
- Arbitrary custom marshalers are intentionally treated as opaque.
- OpenAPI export produces component schemas rather than route-level API
  documents.
- Git revision comparison uses locally available revisions and dependencies
  and never fetches automatically.
